# Legal Errand API

This is the backend API for Legal Errand.

## Base URL

The local development base URL is:
**`http://localhost:5000/api/v1`**

## Environment Variables

Make sure you have a `.env` file in the root directory. You can copy the contents of `.env.example` if available. The primary configuration defaults to port `5000`.

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```

3. **Start the Production Server**
   ```bash
   npm start
   ```

## API Prefix

All API routes are prefixed with `/api/v1`.
